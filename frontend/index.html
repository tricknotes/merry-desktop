        WSL との連携

        チェックしたディストリの docker CLI から、この VM を使えます(ディストリのファイルのバインドマウントも使えます)。

          ビルドのプロキシ

          docker の設定ファイル(~/.docker/config.json)の proxies に、検出したプロキシを書き込みます(元のファイルはバックアップします)。自分で設定した proxies は変更しません。パスワードつきのプロキシは書き込みません。

            コンテナの証明書

            社内のプロキシが TLS を検査していると、コンテナの中の npm、pip、curl、git が証明書エラーになります。オンにすると、VM の証明書の束を /etc/ssl/merry-desktop/ca-certificates.crt に読み取り専用でマウントし、SSL_CERT_FILE などの環境変数でそれを指します。コンテナが自分で設定した値は変えません。作り直したコンテナから反映されます。
